# Cybersecurity Learning Roadmap

This roadmap organizes my learning path into cybersecurity, ethical hacking and penetration testing.

My goal is to build strong foundations before moving into more advanced practical labs.

## Phase 1 - Foundations

Focus areas:

- Networking fundamentals
- Linux basics
- Git and GitHub
- Basic programming
- Command line usage

Expected outcomes:

- Understand basic TCP/IP concepts
- Use Linux commands comfortably
- Document notes and labs on GitHub
- Review programming fundamentals
- Build small scripts

## Phase 2 - Security Basics

Focus areas:

- Cybersecurity concepts
- Common vulnerabilities
- Authentication and authorization
- Password security
- Web security basics
- Logs and monitoring

Expected outcomes:

- Understand basic security principles
- Learn common attack and defense concepts
- Identify why vulnerabilities happen
- Start analyzing logs and simple security events

## Phase 3 - Practical Labs

Focus areas:

- Legal and controlled lab environments
- Capture The Flag exercises
- Basic enumeration
- Port scanning concepts
- Web security labs
- Writeups and documentation

Expected outcomes:

- Practice only in authorized environments
- Write clear lab notes
- Understand the methodology behind ethical hacking
- Connect networking, Linux and security concepts

## Phase 4 - Small Projects

Possible projects:

- Basic port scanner
- Log analyzer
- Security headers checker
- Password strength checker
- Network troubleshooting notes
- Wireshark traffic analysis writeups

## Weekend Study Routine

My current available study time is mostly on weekends.

A simple structure:

1. Learn one small concept
2. Practice it in a controlled environment
3. Write notes in this repository
4. Add examples, screenshots or commands when useful
5. Review what I learned before moving forward

## Ethics

All cybersecurity learning and testing must be done legally and ethically.

I will only practice in:

- My own systems
- Intentionally vulnerable labs
- Platforms that allow security practice
- Environments where I have explicit permission
